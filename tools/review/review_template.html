The large token is what the module will use. Click an alternative to swap, or browse everything. Tick Looks right when you're happy with a line. Your choices are saved in this browser.

Your own art lives in the custom-tokens folder next to this page. Name each file after the monster: Book Mimic-1.png for the portrait and Book Mimic token-2.png for the token (an optional … subject.png is a token-ring cutout). Case, spaces, hyphens and the numbers at the end don't matter, and for a name with a comma like Dregatha, Thrice-Chinned, a file starting with Dregatha, matches. After adding files, click Load my art folder… and pick the custom-tokens folder to see them here.
